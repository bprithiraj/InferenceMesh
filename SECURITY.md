# Security Policy

## Supported versions

InferenceMesh is a pre-1.0 personal project and does not provide an uptime or
security-response SLA. Security fixes are considered for the latest released
`0.1.x` version only.

## Reporting a vulnerability

Do not disclose vulnerabilities, credentials, private prompts, or customer
data in public issues, pull requests, or discussions.

Before the repository is made public, the maintainer must either enable GitHub
private vulnerability reporting or publish a monitored, non-corporate security
contact. Until one of those channels exists, this repository is not ready to
accept vulnerability details from the public.
